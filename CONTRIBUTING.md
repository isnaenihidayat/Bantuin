# Contributing

## Workflow

1. Start from an approved direct sprint plan.
2. Create a focused feature branch from `main`.
3. Keep commits atomic and use Conventional Commit subjects.
4. Run the repository quality gates before requesting review.
5. Record manual and state verification in the sprint report.
6. Merge to `main` only after CI and user confirmation.

## Safety

Do not commit secrets or runtime data. New provider, tool, network, authentication, migration, or automation behavior requires tests for failure paths and an updated threat assessment.
