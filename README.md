# Bantuin

Bantuin is a self-hostable, Bahasa-Indonesia-first personal AI assistant. It is currently in foundation development.

The implementation plan lives in [`process/features/personal-ai-assistant/active/`](process/features/personal-ai-assistant/active/).

## Current status

- Sprint 1: foundation
- Runtime: Bun + TypeScript
- Initial provider: OpenRouter
- Database: SQLite
- Default network posture: local-only

Application setup instructions will be added after the Sprint 1 scaffold is verified.
